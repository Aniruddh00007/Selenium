# Selenium WebDriver – Practice Repository

This repository contains Java code and practical examples written while learning Selenium WebDriver and Automation Testing.

It covers basic Selenium concepts, locators, WebElement handling, mouse and keyboard actions, dropdowns, screenshots, TestNG, Maven, and Page Object Model (POM).

The purpose of this repository is to track my learning journey and improve my hands-on automation testing skills.

More practice programs and concepts will be added as I continue learning.
